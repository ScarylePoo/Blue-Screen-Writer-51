Blue Screen Writer 51
=====================

Full guide for 5.1 users: "Guide - What Is New.docx" in this folder
(open it with Shift-F10 or F5 in Blue Screen Writer 51, or in Word).

Start: double-click bsw51.exe  (keep the folders dict, thes, hyph and WPM
next to it).

The keyboard works exactly like the classic 5.1 layout with the Alternate
keyboard: F1 = Help, Esc = Cancel/Undelete, F3 = Repeat.  Change it in
Shift-F1 Setup -> 3 Environment -> 9 Alternate Keyboard, or pick a .WPK file
in Shift-F1 -> 5 Keyboard Layout.

Your own macros (.WPM) and keyboard files (.WPK): copy them into the WPM
folder.  Alt-letter macros and Alt-F10 then work as before.

Mouse (optional): click = place cursor, drag = Block, double-click = word,
wheel = scroll, right button or Alt-= = pull-down menu bar.

FILES
 Saved as Word files (.docx) - opens in Word, LibreOffice, etc.
 Opens: .docx .doc .rtf .odt WP 4.2-6 (.wp .wp5 .wpd ...), Outlook .msg,
 and like Notepad any other file as text.
 Arabic (right to left), Chinese, Japanese and Korean are supported.
 F5 List Files: long names, spaces, network drives, \\server\share paths.
 Ctrl-F5 3 Save As: Word, PDF, ODT, RTF, HTML, text (several encodings).
 Double-click documents in Windows: Shift-F1 -> 7 -> Register, then choose
 Blue Screen Writer 51 in the Windows "Default apps" window that opens.

SAFETY
 - Recovery copy of unsaved work every 30 seconds; after a crash or power
   cut you are asked to recover it at the next start.
 - Named Word documents are saved automatically every 5 minutes
   (Shift-F1 -> 3 -> 1 Backup Options).
 - Every save is kept: Ctrl-F5 -> 6 Revisions (look, retrieve, compare,
   restore).  Survives editing the file in Word.
 - Undo Ctrl-Z, Redo Ctrl-Y (plus the classic Undelete).

SCREEN
 Large letters like the classic screen: 80 columns fill the window.
 Smaller letters: Ctrl+Shift+minus (or Ctrl + mouse wheel).  Larger again:
 Ctrl+=.  Ctrl+0 = normal.  Shift-F1 -> 2 Display -> 5 Screen Size.

PRINT
 Shift-F7: 1 Full Document, 2 Page, 6 View Document, S Select Printer.

Settings, revisions and recovery copies live in
%APPDATA%\Blue Screen Writer 51
