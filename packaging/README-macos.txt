Blue Screen Writer 51 for macOS
===============================

Drag "Blue Screen Writer 51.app" into Applications (or anywhere) and open
it.  It runs natively on Apple Silicon and Intel Macs (macOS 11 or newer).

First start: the app is not signed by Apple, so macOS says it "cannot be
opened" or "cannot check it for malicious software".  Then either
  - right-click (Control-click) the app, choose Open, then Open again, or
  - in System Settings > Privacy & Security, click "Open Anyway".
macOS remembers this; afterwards it opens normally.

Keys: the Option key is Alt.  For F1-F12 hold the fn key, or turn on
"Use F1, F2, etc. keys as standard function keys" in System Settings >
Keyboard.  Some function keys are used by macOS itself (Mission Control,
Show Desktop ...): switch those shortcuts off in System Settings >
Keyboard > Keyboard Shortcuts if you need the keys here.

Not available on macOS yet: printing and PDF (they use the Windows printer
system).  Save as .docx or .odt (Ctrl-F5, 3) and print from Pages, Word or
LibreOffice.  Registering as the default program (Setup 7) is Windows only.

Your macros (.WPM) and keyboards (.WPK) go into
~/.config/blue-screen-writer-51/WPM ; settings, revisions and recovery
copies are in ~/.config/blue-screen-writer-51

Full manual: https://github.com/ScarylePoo/Blue-Screen-Writer-51/wiki
