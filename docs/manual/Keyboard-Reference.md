# Keyboard Reference

All keys of Blue Screen Writer 51 on one page. Keys are shown for the standard **Alternate keyboard**; the three keys that differ on the original keyboard are listed first.

## Alternate and original keyboard

| Key | Alternate keyboard (standard) | Original keyboard |
|---|---|---|
| **F1** | Help | Cancel / Undelete |
| **F3** | Repeat | Help |
| **Esc** | Cancel / Undelete | Repeat |

Switch in **Shift-F1**, **3**, **9**. A `.WPK` keyboard file (Shift-F1, 5) can change any key.

## Cursor movement

| Key | Moves |
|---|---|
| **Left** / **Right** | One character |
| **Up** / **Down** | One line |
| **Ctrl-Left** / **Ctrl-Right** | One word |
| **Ctrl-Up** / **Ctrl-Down** | One paragraph |
| **End** | End of the line |
| **Home**, **Left** / **Home**, **Right** | Start / end of the line |
| **Home**, **Up** / **Home**, **Down** | Top / bottom of the screen, then a screen further |
| grey **-** / grey **+** | Screen up / screen down |
| **Page Up** / **Page Down** | Previous / next page |
| **Home**, **Home**, **Up** / **Down** | Beginning / end of the document |
| **Home**, **Home**, **Home**, **Up** | Beginning of the document, before all codes |
| **Home**, **Home**, **Home**, **Left** | Start of the line, before all codes |
| **Ctrl-Home** | Go To: page number + Enter; a character; Up / Down = top / bottom of page; Left / Right = previous / next column |
| **Alt + arrow keys** | In a table: neighbouring cell; elsewhere: word / paragraph |
| **Tab** / **Shift-Tab** | In a table: next / previous cell |

## Mouse

| Action | Effect |
|---|---|
| Click | Place the cursor; choose a menu item; select a list line |
| Double-click | Select a word; open a file or list item |
| Drag | Mark a Block |
| Wheel | Scroll |
| Ctrl + wheel | Zoom |
| Right button | Menu bar (in a menu or prompt: Cancel) |
| Ctrl + click on a link | Open the link |

## Keys inside menus and prompts

| Key | Effect |
|---|---|
| Number or highlighted letter | Choose |
| **Esc** (Cancel) | Back one step |
| **Enter**, **Space**, **0** | Leave the menu |
| **F7** (Exit) | Accept a typed value; leave all menus and return to the document |
| **Up** at `Document to be retrieved:` | Recent documents |
