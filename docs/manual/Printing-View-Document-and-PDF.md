# Printing, View Document and PDF

Blue Screen Writer 51 prints to **any Windows printer**, with Windows TrueType and OpenType fonts and pictures. It also makes PDF files.

## The Print screen (Shift-F7)

Press **Shift-F7** (Print):

```
Print

     1 - Full Document
     2 - Page
     3 - Document on Disk
     4 - Control Printer
     5 - Multiple Pages
     6 - View Document
     7 - Initialize Printer

Options

     S - Select Printer                 HP LaserJet (Windows default)
     B - Binding Offset                 0"
     N - Number of Copies               1
     U - Multiple Copies Generated by   Blue Screen Writer 51
     G - Graphics Quality               Medium
     T - Text Quality                   High
```

| Choice | What it does |
|---|---|
| **1 Full Document** | Prints the whole document. |
| **2 Page** | Prints the page the cursor is on. |
| **3 Document on Disk** | Prints a document file without opening it. Type its name at `Document name:`. |
| **4 Control Printer** | Print jobs are handled by Windows; this shows a reminder to look at the printer's queue in Windows. |
| **5 Multiple Pages** | Type the pages at `Page(s):`, for example `2`, `2,4-5`, or `3-` (page 3 to the end). |
| **6 View Document** | Shows the pages on the screen exactly as they will be printed (see below). |
| **S Select Printer** | Choose one of the printers installed in Windows (see below). |
| **N Number of Copies** | How many copies to print (1–999). |

The status line confirms what was sent, for example `* Sent 3 page(s) to HP LaserJet *`.

*Not available in this version:* **7 Initialize Printer** (not needed for Windows printers), and changing **B** Binding Offset, **U** Multiple Copies Generated by, **G** Graphics Quality and **T** Text Quality. These are shown for completeness; the Windows printer driver decides quality and binding.

### Printing a Block

Mark the text as a Block, press **Shift-F7**, and answer `Print block?` with **Y**.

### Printing from List Files

In **F5** List Files, highlight a document and press **4** (Print).

## Selecting a printer

1. Press **Shift-F7**, **S**.
2. The list shows all printers installed in Windows. The one in use is marked with `*`; the Windows default printer is marked *(Windows default)*.
3. Move with the arrow keys (or click) and press **1** (Select) or **Enter** (or double-click).

The choice is kept for next time. If you never choose one, the Windows default printer is used.

To add a printer, use Windows Settings, *Bluetooth & devices*, *Printers & scanners*.

## View Document

**Shift-F7**, **6** shows the current page exactly as it will be printed: real fonts, pictures, headers and footers, footnotes, page numbers and lines.

The bottom line shows:

```
1 100%  2 200%  3 Full Page  4 Facing Pages: 3                Doc 1 Pg 1
```

| Key | Effect |
|---|---|
| **1** | 100% (actual size) |
| **2** | 200% (enlarged) |
| **3** | Full page (the standard) |
| **4** | Facing pages (two pages side by side, as in a book) |
| **Page Down** / **Page Up** | Next / previous page (two at a time in Facing Pages) |
| **Arrow keys** | Scroll the enlarged page |
| grey **+** / **-** | Scroll down / up by a larger step |
| **Home** | Back to the top left corner of the page |
| **F7** | Back to the document |
| **Esc**, **Enter**, **Space**, **0** | Back to the Print screen |

## Making a PDF

There are two ways:

1. **Ctrl-F5** (Text In/Out), **3** (Save As), **2** (PDF). Type the file name (the document's name ending in `.pdf` is offered) and press **Enter**. The status line confirms `* Saved … *`.
2. Or choose **Microsoft Print to PDF** as the printer (Shift-F7, S) and print. Windows then asks for the file name.

Both use the "Microsoft Print to PDF" printer that comes with Windows 10 and 11. If it has been removed, the message `ERROR: No PDF printer installed (Microsoft Print to PDF)` appears; you can add it again in Windows Settings (*Optional features* or *Printers & scanners*).

## Fonts

- **Ctrl-F8**, **4** (Base Font) and **Shift-F8**, **3**, **3** (Initial Base Font) list all fonts installed in Windows. See [Formatting](Formatting).
- Fonts from old WordPerfect documents (for example *Times Roman*, *Helvetica*, *Courier*) are replaced by the matching Windows fonts automatically.
- Chinese, Japanese and Korean text uses Microsoft YaHei, Yu Gothic and Malgun Gothic.
- The editing screen always uses its own clear fixed-width screen font; the real fonts are used in View Document, printing and PDF.

## Pictures

Pictures in graphics boxes (PNG, JPEG, BMP, GIF and WPG) are printed in colour or grey depending on the printer. See [Graphics](Graphics).

## Envelopes and labels

Set the paper size with **Shift-F8**, **2**, **7** (Envelope, or a Labels definition), then print as usual. See [Formatting](Formatting) and [Merge and Sort](Merge-and-Sort).
