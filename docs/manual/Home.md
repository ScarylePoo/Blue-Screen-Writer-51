# Blue Screen Writer 51 User Manual

**Blue Screen Writer 51** (`bsw51.exe`) is a word processor for Windows 10 and 11 that works the way WordPerfect 5.1 for DOS worked: the blue screen, the function keys, the menus at the bottom of the screen, and **Reveal Codes**. It is a real Windows program, not a DOS emulator, and it adds the safety nets and file formats of a modern editor.

## Who it is for

Many people wrote with WordPerfect 5.1 for decades, and their hands still know every key. Some of them still use it inside DOSBox or vDos. Blue Screen Writer 51 lets you keep working exactly that way:

- the same keys and menus, so you do not have to learn anything new;
- long file names, network drives and Windows printers;
- documents saved as ordinary **Word documents (.docx)** that anyone can open;
- **Undo**, automatic **crash recovery**, **automatic saving** and a full **history of every saved version**;
- spell checking as you type, track changes compatible with Word, PDF, and much more.

Everything new is optional. You can ignore all of it and simply keep working as before.

Blue Screen Writer 51 is a clean-room program written from scratch. It contains no WordPerfect code. It is free and its source code is public domain.

## Quick start

1. Download the zip file from the project's **Releases** page and unzip it, for example into your *Documents* folder. See [Installation and Starting](Installation-and-Starting).
2. Double-click **bsw51.exe**.
3. Type your text. Use the function keys as you always did: **F6** Bold, **F8** Underline, **Shift-F8** Format, **Ctrl-F8** Font.
4. Press **F11** (or **Alt-F3**) to see **Reveal Codes**.
5. Press **F10** to save. The document is saved as a Word file (.docx).
6. Press **F7** to leave.

**The keyboard:** the program starts with the *Alternate keyboard*: **F1 = Help**, **Esc = Cancel/Undelete**, **F3 = Repeat**. If you prefer the original layout (F1 Cancel, F3 Help, Esc Repeat), switch it in **Shift-F1** Setup, **3** Environment, **9** Alternate Keyboard. See [The Screen and Keyboard](The-Screen-and-Keyboard).

**New keys you may want right away:**

| Key | What it does |
|---|---|
| **Ctrl-Z** / **Ctrl-Y** | Undo / Redo |
| **Ctrl-Ins** / **Shift-Del** / **Shift-Ins** | Copy / Cut / Paste with other Windows programs |
| **Alt-=** or right mouse button | Pull-down menu bar |
| **Shift-F10**, then **Up arrow** | The last documents you used |
| **Ctrl + =** / **Ctrl + Shift + minus** / **Ctrl + 0** | Larger / smaller / normal letters |
| **Ctrl-F5**, **6** | Revisions: every saved version of the document |
