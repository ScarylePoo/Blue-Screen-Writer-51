Hyphenation patterns (libhyphen / TeX format) used by Blue Screen Writer 51
==========================================================================

All files were taken unchanged from the LibreOffice dictionaries repository
(https://github.com/LibreOffice/dictionaries), only renamed to hyph_xx_YY.dic.
The hyphenation algorithm itself (Liang) is implemented in src/hyph.rs.
